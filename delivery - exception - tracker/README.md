# Delivery Exception Tracking System

A simple web-based dashboard for managing and tracking delivery exceptions.

## Project Description

Delivery companies handle many orders every day. Sometimes deliveries may be delayed, damaged, sent to the wrong address, or the customer may not be available.

This project provides an internal dashboard where the operations team can record these delivery exceptions and track their status.

## Features

- Add delivery exceptions
- Store order details
- Select different issue types
- Track Pending, In Progress and Resolved issues
- Search delivery exceptions
- Filter issues by status
- Delete exceptions
- Dashboard statistics
- Data persistence using Local Storage
- Responsive user interface

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Add delivery exceptions using the form.
5. Track and update their status.
